# 🔍 Consulta CPF - Python API

Sistema de consulta de CPF desenvolvido em Python utilizando integração com API via Key, contando com interface moderna em CustomTkinter e foco em praticidade na busca de informações.

---

## 🚀 Tecnologias Utilizadas

* Python
* CustomTkinter
* Requests
* Python Dotenv

---

## ✨ Funcionalidades

* Consulta de CPF em tempo real
* Integração com API privada
* Interface gráfica moderna
* Exibição formatada dos dados
* Tratamento de erros
* Suporte a API Key via `.env`

---

## 📸 Interface

Interface moderna desenvolvida com CustomTkinter utilizando tema dark minimalista.

---

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/NOME-DO-REPOSITORIO.git
```

Instale as dependências:

```bash
pip install customtkinter requests python-dotenv
```

Crie um arquivo `.env`:

```env
API_KEY=SUA_API_KEY
```

Execute o projeto:

```bash
python app.py
```
